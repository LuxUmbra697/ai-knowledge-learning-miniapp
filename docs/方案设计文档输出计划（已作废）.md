# Plan: LuxUmbra AI 闯关学习小程序 — 方案设计文档

## TL;DR

为"LuxUmbra AI 闯关学习小程序"编写完整的技术方案设计文档，涵盖小程序框架选型对比、后端架构（Python FastAPI + DeepSeek）、核心 Prompt 设计、数据模型、分阶段开发计划。优先跑通「用户输入 → AI 出题 → 答题闯关 → 生成报告」的核心闭环，数据库和用户登录等延后处理。

## 用户确认的技术偏好

- 后端语言：Python (FastAPI/Flask) todo AI大模型的对接使用 Python 的 LangChain 框架
- AI 大模型：DeepSeek (deepseek-chat / deepseek-reasoner，OpenAI 兼容 API)
- 数据库：大概率 MySQL，但非核心 MVP 必须
- 部署方式：暂不考虑
- 联网搜索：非核心 MVP，先让 AI 直接出题
- 开发人数：一人独立开发
- 小程序框架：需要详细对比后推荐

## Decisions

- 后端选 FastAPI（用户确认），不用 Flask（FastAPI 异步性能更好，自带 OpenAPI 文档）
- DeepSeek API 使用 OpenAI SDK 兼容模式调用（base_url 改为 https://api.deepseek.com）
- MVP 阶段不做联网搜索，AI 直接基于输入内容出题
- MVP 阶段不做用户登录注册，先跑通核心答题流程
- 小程序框架推荐：待对比后确定（倾向 uni-app Vue3 版）
