# 微信隐私与提审

## 后台声明

应用内 `/pages/privacy/index` 可公开阅读，但不能替代公众平台的《用户隐私保护指引》。运营者在“设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引”填写真实主体、联系渠道、保存期限与实际用途。不要填写虚构邮箱；本应用不额外展示邮箱。

以下按当前代码核对，不要为提审勾选未使用的数据类型：

| 数据或能力 | 触发场景与用途 | 用户选择 |
| --- | --- | --- |
| 微信 code / OpenID | 点击微信登录后识别账号、关联本人的学习记录 | 可取消或使用账号密码 |
| 自定义账号、密码、昵称 | 主动注册或编辑；密码保存哈希 | 不索取微信头像、手机号、通讯录或定位 |
| 主动选择的消息文件 | 点击添加材料后选择 PDF、DOCX、TXT、Markdown，用于解析、问答和练习 | 文件隐私说明确认后才打开选择器；取消不上传 |
| 学习问题、作答、复习与对话 | 主动使用功能时处理，按账号保存 | 材料和伙伴记忆可删除，不与其他账号共享 |
| AI 与存储服务 | DeepSeek / 百炼处理必要问题与片段；腾讯云数据库/COS保存学习数据，OSS提供公共图片 | 不自动向网页搜索发送私人知识库 |
| 本机设置与登录态 | 保存外观、伙伴位置、草稿及登录凭据 | 可调整设置、退出登录；退出不等于删除服务器记录 |

供应商的个人信息处理约定、联系渠道与保存期限，须按实际运营填写。当前没有整账号自助注销按钮，不能宣称已有该能力；其他数据权利请求通过平台公示渠道提出并验证身份。

## 代码行为

1. 启动展示可浏览首页，不请求微信、手机号或头像授权。
2. 点击私人功能时询问是否登录，拒绝后保持首页；私人深链接也可取消并返回首页。
3. 小程序提供微信、账号登录和注册。未登记微信先确认注册或绑定，不自动建号。
4. 文件隐私提示只在点击添加材料后出现；查看指引调用 `openPrivacyContract`。同意按钮使用官方 `open-type="agreePrivacyAuthorization"`，仅确认回调后选择文件。
5. 取消不上传、不改变登录状态。声明缺失时保留平台错误，不关闭校验来冒充通过。

## 重新提审

登录微信开发者工具，核对 AppID、生产包与合法 HTTPS 域名。测试首次游客、拒绝登录、三个登录选项、真实微信 code、恢复码、拒绝文件授权和上传。用真实设备录制“启动 → 浏览 → 自愿登录 → 功能”，不要录入密码或恢复码。

上传开发版本、设置体验版、提交审核和正式发布是不同状态。后台保存隐私声明后，仍需重新上传/提审，并以平台结果为准。

参考：[官方隐私授权指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)、[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)。
