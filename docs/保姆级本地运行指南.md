# LuxUmbra AI 闯关学习小程序 - 保姆级本地运行指南

本文档手把手带你从零开始，在本地把这个项目跑起来。按照步骤来，不会跳过任何细节。

这个项目是 **前后端分离** 的，需要同时跑两个东西：

- 后端：Python + FastAPI 服务，跑在本地 8000 端口
- 前端：Taro 编译出的微信小程序，用微信开发者工具打开预览



> 当然，你也可以直接让 AI 帮你运行，只需要跟着它的引导去提供一些 API Key 啥的就好~



## 前置要求

请确保你的电脑上已经安装了以下软件：

## 第二步、获取 API Key

这一步是整个项目最花时间的地方，建议先把 Key 都申请好再往下走。

**只有 DeepSeek 是必需的**，其他都是可选的，不配置只会让对应功能不可用，不影响项目启动和核心的出题答题流程。

### 2.1 DeepSeek API Key ✅ 必需

用途：AI 出题和生成复盘报告，不配置项目的核心功能就没法用。

获取步骤：

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并登录
2. 进入左侧的「API keys」页面，点击「创建 API key」
3. 复制生成的 Key（格式类似 `sk-xxxxxxxx`），**只显示一次，记得马上保存**
4. 到「充值」页面充一点钱，DeepSeek 很便宜，充 10 元足够你把项目跑很多遍



### 2.2 Tavily API Key 🔧 可选

用途：AI 出题前先联网搜索最新资料，让题目不过时。不配置的话，项目会自动降级为用大模型自己的知识出题，功能正常但题目可能过时。

获取步骤：

1. 访问 [Tavily 官网](https://tavily.com/)，用 GitHub 或邮箱注册
2. 登录后进入后台，直接就能看到 API Key（格式类似 `tvly-xxxxxxxx`）
3. 免费额度每月有 1000 次搜索，学习完全够用



### 2.3 阿里云百炼 API Key 🔧 可选

用途：一个 Key 管两件事，知识库 RAG 的文本向量化（Embedding），以及题目配图的 AI 生图。不配置的话，知识库和配图功能不可用。

获取步骤：

1. 访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，用阿里云账号登录并开通服务
2. 在右上角的「API-KEY」入口创建一个 API Key（格式类似 `sk-xxxxxxxx`）
3. 确认你的 Key 已开通 `text-embedding-v4`（向量模型）和 `qwen-image`（文生图模型）的调用权限

> **注意**：部分以 `sk-ws-` 开头的工作空间 Key 会按用途限定权限范围，Embedding 和生图可能需要各自的 Key。如果生图一直失败但向量化正常，就单独申请一个 Key 填到 `DASHSCOPE_IMAGE_API_KEY` 里。



### 2.4 腾讯云 COS 对象存储 🔧 可选

用途：把 AI 生成的题目配图转存下来，得到永久访问链接。不配置的话，配图功能不可用（因为生图接口返回的临时链接会过期，不能直接用）。

获取步骤：

1. 访问 [腾讯云 COS 控制台](https://console.cloud.tencent.com/cos)，开通对象存储服务
2. 点击「存储桶列表」到「创建存储桶」，地域随便选一个离你近的（比如上海 `ap-shanghai`），**访问权限必须选「公有读私有写」**，否则小程序加载不到图片
3. 记下存储桶名称（格式是 `桶名-数字APPID`，比如 `my-quiz-1250000000`）和所属地域
4. 到 [访问管理的密钥页面](https://console.cloud.tencent.com/cam/capi) 创建密钥，拿到 SecretId 和 SecretKey



### 2.5 微信小程序 AppID 和 AppSecret 🔧 可选

用途：微信登录。不配置的话，你依然能完整体验出题、答题、看报告的核心流程（项目做了「可选登录」设计），只是记录不会保存，而且知识库和生图这两个必须登录的功能用不了。

本地开发建议直接用 **测试号**，免注册、免审核，一分钟搞定：

1. 访问 [微信小程序测试号申请页面](https://developers.weixin.qq.com/sandbox)
2. 用微信扫码，页面上立刻就会给你一个 AppID 和 AppSecret，直接复制

> 如果你要做正式上线，才需要到 [微信公众平台](https://mp.weixin.qq.com/) 注册正式的小程序账号。



## 第三步、配置环境变量

### 3.1 创建配置文件

```bash
cd backend
cp .env.example .env
```



### 3.2 填写配置

用编辑器打开 `backend/.env`，按下面的说明填写。**标注「必填」的一定要改，标注「选填」的可以先留着默认值。**

```bash
# ===== DeepSeek 大模型（必填）=====
DEEPSEEK_API_KEY=sk-你申请的key        # 必填，第 2.1 步获取
DEEPSEEK_BASE_URL=https://api.deepseek.com   # 选填，保持默认
DEEPSEEK_MODEL=deepseek-chat                 # 选填，保持默认

# ===== Tavily 联网搜索（选填）=====
TAVILY_API_KEY=tvly-你申请的key        # 选填，不填会自动降级
ENABLE_WEB_SEARCH=true                 # 选填，想彻底关掉搜索就改成 false

# ===== 阿里云百炼 Embedding（选填，知识库功能需要）=====
DASHSCOPE_API_KEY=sk-你申请的key       # 选填，用知识库就必须填
DASHSCOPE_EMBEDDING_MODEL=text-embedding-v4                        # 选填，保持默认
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1   # 选填，保持默认

# ===== 知识库参数（全部选填，保持默认即可）=====
CHROMA_PERSIST_DIR=./data/chroma       # 向量库存放目录
KB_UPLOAD_DIR=./data/uploads           # 上传文件存放目录
KB_MAX_DOCUMENTS_PER_USER=10           # 每人最多存几篇文档
KB_MAX_FILE_SIZE_MB=10                 # 单个文件最大多少 MB
KB_CHUNK_SIZE=1000                     # 文档分块大小
KB_CHUNK_OVERLAP=150                   # 分块之间的重叠字符数
KB_RETRIEVE_TOP_K=4                    # 检索时取最相关的几个分块

# ===== AI 生图（选填，配图功能需要）=====
DASHSCOPE_IMAGE_MODEL=qwen-image-2.0   # 选填，保持默认
DASHSCOPE_IMAGE_API_KEY=               # 选填，留空则复用上面的 DASHSCOPE_API_KEY
DASHSCOPE_IMAGE_BASE_URL=              # 选填，留空则自动推导
IMAGE_GEN_SIZE=512*512                 # 选填，生成图片的尺寸
IMAGE_GEN_DAILY_LIMIT=20               # 选填，每人每天最多生成几张
IMAGE_GEN_MAX_CONCURRENCY=5            # 选填，同时生成几张

# ===== 腾讯云 COS（选填，配图功能需要）=====
COS_SECRET_ID=你的SecretId             # 选填，用配图就必须填
COS_SECRET_KEY=你的SecretKey           # 选填，用配图就必须填
COS_REGION=ap-shanghai                 # 选填，改成你存储桶的实际地域
COS_BUCKET=你的桶名-数字APPID          # 选填，用配图就必须填
COS_UPLOAD_PREFIX=quiz-images/         # 选填，图片在桶里的目录前缀
COS_DOMAIN=                            # 选填，有 CDN 加速域名才填

# ===== 后端服务（全部选填）=====
APP_HOST=0.0.0.0
APP_PORT=8000
APP_DEBUG=true

# ===== MySQL（必填密码）=====
MYSQL_HOST=localhost                   # 选填，本地保持默认
MYSQL_PORT=3306                        # 选填，本地保持默认
MYSQL_USER=root                        # 选填，改成你的 MySQL 用户名
MYSQL_PASSWORD=你的MySQL密码           # 必填，改成你本机 MySQL 的真实密码
MYSQL_DATABASE=luxumbra_ai_learn      # 选填，保持默认
MYSQL_CHARSET=utf8mb4                  # 选填，保持默认
MYSQL_POOL_MINSIZE=1                   # 选填，连接池最小连接数
MYSQL_POOL_MAXSIZE=10                  # 选填，连接池最大连接数
MYSQL_AUTO_INIT=true                   # 选填，务必保持 true，启动时自动建库建表

# ===== 微信小程序（选填，登录功能需要）=====
WECHAT_APP_ID=你的AppID                # 选填，用登录就必须填，第 2.5 步获取
WECHAT_APP_SECRET=你的AppSecret        # 选填，用登录就必须填

# ===== 日志（选填）=====
LOG_LEVEL=INFO                         # 想看详细日志可以改成 DEBUG
```



### 3.3 补一个 .env.example 里没有的配置

`.env.example` 里 **没有列出 `JWT_SECRET`**，但代码里是支持的，它的默认值是 `change-me-in-production`。本地开发用默认值没问题，但如果你要部署上线，**必须** 在 `.env` 里手动加一行改掉，否则任何人都能伪造登录凭证：

```bash
# 登录令牌签名密钥，上线必须改成一个随机长字符串
JWT_SECRET=换成你自己的一长串随机字符
JWT_EXPIRE_MINUTES=43200
```



## 第四步、安装依赖

### 4.2 前端依赖

**新开一个终端窗口**，不要关掉后端那个：

```bash

```

```bash
npm install --registry=https://registry.npmmirror.com
```



## 第五步、初始化数据库

### 5.1 启动 MySQL 服务

- macOS（Homebrew 安装）：`brew services start mysql`
- Windows：在「服务」里启动 MySQL，或用 MySQL 安装器自带的方式启动
- Linux：`sudo systemctl start mysql`



### 5.2 建库建表

**你什么都不用做。** 只要 `.env` 里的 `MYSQL_AUTO_INIT=true`（默认就是），后端启动时会自动创建数据库和全部 7 张表。

如果你想手动初始化，在 `backend` 目录下执行：

```bash
python3 scripts/init_mysql.py
```

成功的话会输出类似这样的日志：

```
{"database": "luxumbra_ai_learn", "event": "mysql_initialized", "level": "info"}
{"event": "mysql_pool_closed", "level": "info"}
```

> **重要提醒**：仓库里的 `backend/sql/init_mysql.sql` 文件 **只包含 4 张基础表**，缺少 `quiz_tasks`（异步出题任务）、`kb_documents`（知识库文档）、`image_generation_logs`（生图流水）这 3 张表。**请不要用这个 SQL 文件来建表**，否则出题、知识库、生图功能都会报错。完整的表结构定义在 `backend/app/core/db.py` 里，用上面两种方式初始化才是完整的。



### 5.3 验证表是否创建成功

用任意 MySQL 客户端连上去看一眼：

```sql
USE luxumbra_ai_learn;
SHOW TABLES;
```

应该看到 7 张表：

```
+------------------------+
| Tables_in_luxumbra_ai_learn  |
+------------------------+
| answer_records         |
| image_generation_logs  |
| kb_documents           |
| quiz_sessions          |
| quiz_tasks             |
| reports                |
| users                  |
+------------------------+
```



## 第六步、启动项目

这一步需要 **两个终端窗口同时开着**。

### 6.1 终端一：启动后端

```bash
cd backend
source venv/bin/activate   # Windows 用 venv\Scripts\Activate.ps1
python3 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

看到下面这样的输出，说明后端启动成功了：

```
{"host": "0.0.0.0", "port": 8000, "event": "app_starting", "level": "info"}
{"database": "luxumbra_ai_learn", "event": "mysql_initialized", "level": "info"}
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

验证一下，浏览器打开 [http://localhost:8000/docs](http://localhost:8000/docs)，能看到 FastAPI 自动生成的接口文档页面，就说明后端完全正常了。你还可以打开 [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)，应该返回：

```json
{"code":0,"message":"ok","data":{"status":"ok"}}
```



### 6.2 终端二：编译前端

```bash
cd frontend
npm run dev:weapp
```

看到下面这样的输出，说明编译成功并进入了监听模式：

```
✔ Webpack
  Compiled successfully in 12.34s

监听文件修改中...
```

**这个终端要一直开着**，它会监听你的代码改动并自动重新编译。



### 6.3 用微信开发者工具打开

1. 打开微信开发者工具，选择「小程序」，点击「+」新建项目
2. **目录一定要选 `frontend/dist`**，不是 `frontend`，因为 `dist` 才是 Taro 编译出来的小程序代码
3. AppID 填你第 2.5 步申请的测试号 AppID（不填登录功能用不了）
4. 后端服务选「不使用云服务」，点击「确定」



### 6.4 关闭域名校验（本地开发必做）

小程序默认只允许请求配置过白名单的 HTTPS 域名，而我们本地后端是 `http://localhost:8000`，会被直接拦截。

解决办法：在微信开发者工具里点击右上角「详情」到「本地设置」，**勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。

> 这一步几乎是所有人本地开发的第一个坑，忘了勾就会看到所有接口请求全部失败。



## 第七步、访问使用

在微信开发者工具的模拟器里，按下面的流程快速体验一遍：

1. **首页输入**：在输入框里随便输入一个你想学的知识，比如「RAG 和传统搜索有什么区别」
2. **选择参数**：选一下题目数量，如果你配好了百炼和 COS，可以勾上「生成配图」
3. **开始生成**：点击「开始生成题目」，然后耐心等。因为要联网搜索加大模型推理，**通常要 30 到 60 秒**，界面上会有加载动画，前端每 8 秒会去查一次任务状态，这是正常的
4. **答题闯关**：题目出来后逐题作答，每答完一题立刻能看到对错、正确答案和解析
5. **查看报告**：全部答完后进入复盘报告页，能看到掌握度、薄弱知识点、知识总结和学习建议
6. **个人中心**：切到「我的」，能看到累计经验值和闯关历史，点任意一条能回看当时的报告
7. **知识库**（需要登录 + 百炼 Key）：从「我的」进入知识库，上传一个 PDF 或 Word 文档，等状态变成就绪后，就能基于这篇文档出题了

> 第一次跑的时候建议 **盯着后端终端的日志看**，出题的每一步（敏感词校验、搜索 Agent 调用工具、大模型返回、生图、任务完成）都有日志，出问题一眼就能定位。



## 常见问题

### Q1、pip 安装依赖很慢或者失败

先换国内镜像，再重试：

```bash
pip3 install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果是某个包单独装不上（比如 chromadb），先升级一下 pip 再试：

```bash
pip3 install --upgrade pip
```



### Q2、后端启动报数据库连接错误

依次检查这几项：

1. MySQL 服务是否已经启动
2. `.env` 里的 `MYSQL_PASSWORD` 是不是你本机 MySQL 的真实密码（这是最常见的原因）
3. `MYSQL_USER` 是不是对的，有些人本机不是 root
4. 3306 端口有没有被占用或被防火墙拦截

注意数据库 **不需要你手动创建**，代码会自动执行 `CREATE DATABASE IF NOT EXISTS`。



### Q3、小程序里所有请求都失败，控制台报域名不合法

没有关闭域名校验。在微信开发者工具点右上角「详情」到「本地设置」，勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。

如果还是不行，检查一下后端是不是真的起来了（浏览器访问 `http://localhost:8000/docs` 试试）。



### Q4、一进小程序就报错，或者「我的」页面一直是空的

大概率是没配微信登录。检查 `.env` 里的 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET` 填了没，以及微信开发者工具里的 AppID 是不是和 `.env` 里的 `WECHAT_APP_ID` **是同一个**。这两个地方填的必须一致，不然换取 openid 会失败。

另外，微信开发者工具的模拟器里有些接口会有「正常报错」（比如获取用户信息相关的警告），只要核心流程能跑通就不用管。



### Q5、出题一直转圈，最后提示生成超时或失败

按这个顺序排查：

1. 看后端终端日志，找 `quiz_task_failed` 这条错误日志，里面有具体原因
2. 最常见的是 DeepSeek 的 Key 没配对或者账户没余额，日志里会有 401 之类的报错
3. 如果日志里是 `search_agent_timeout`，说明联网搜索超时了（上限 120 秒），这不影响出题，它会自动降级；如果你网络访问 Tavily 不稳定，可以把 `ENABLE_WEB_SEARCH` 改成 `false` 先跳过搜索
4. 如果是 JSON 解析报错，说明大模型没按格式输出，重试一次通常就好了



### Q6、知识库上传文档后，状态一直是「处理中」或变成「失败」

1. 看后端日志找 `kb_document_processing_failed`，里面有具体错误
2. 最常见的是没配 `DASHSCOPE_API_KEY`，或者这个 Key 没有 `text-embedding-v4` 的权限
3. 如果报错信息里提到 `contents is neither str nor list of str`，说明 Embedding 的兼容模式有问题，检查 `DASHSCOPE_BASE_URL` 是不是 `https://dashscope.aliyuncs.com/compatible-mode/v1`
4. 确认文件格式是 PDF、Word（.docx）、Markdown、纯文本这四种之一，`.doc` 老格式不支持
5. 确认文件不超过 10MB，且你的文档数没超过 10 篇



### Q7、勾了「生成配图」但题目没有图

按这几种情况看：

1. **没登录**：生图必须登录才能用，接口会返回提示「登录后才能使用生成图片功能」
2. **额度用完**：每人每天默认 20 张，用完了会提示，可以改 `IMAGE_GEN_DAILY_LIMIT`
3. **没配 COS**：生图成功但转存失败，图片就用不了。检查 COS 的四个配置项，尤其是存储桶权限必须是「公有读私有写」
4. **百炼 Key 没有生图权限**：日志里会有生图失败的报错，单独申请一个 Key 填到 `DASHSCOPE_IMAGE_API_KEY` 试试
5. 生图失败 **不会影响出题**，题目照样能正常做，这是项目故意做的容错



### Q8、npm install 或者 Taro 编译失败

```bash
# 清理后重装
rm -rf node_modules package-lock.json
npm install --registry=https://registry.npmmirror.com
```

如果编译报 Node 版本相关的错，检查一下 `node -v`，Taro 4 需要 Node 18 及以上。



### Q9、微信开发者工具里看到的还是旧代码

检查两点：

1. 前端那个跑着 `npm run dev:weapp` 的终端是不是还开着、有没有报错
2. 微信开发者工具打开的目录是不是 `frontend/dist`（不是 `frontend`）

改完代码要等 Taro 编译完（终端会输出编译成功），开发者工具才会刷新。



### Q10、8000 端口被占用

```bash
# macOS / Linux 查看占用进程
lsof -i :8000

# Windows 查看占用进程
netstat -ano | findstr :8000
```

杀掉进程后重启，或者改用别的端口：

```bash
python3 -m uvicorn app.main:app --reload --port 8001
```

注意，改了后端端口，前端请求地址也要跟着改（见 `frontend/config/` 下的环境配置）。
